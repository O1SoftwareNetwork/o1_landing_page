Looking for a job in tech?

Project Manager

The project manager position is an opportunity to teach what you know, learn what you don't know, and help others master the key skills in software engineering. A teacher/project manager will manage a project of up to 30 aspiring software engineers building real-world projects on real-world teams with real-world tools like Git, GitHub, Jira, Figma, and a diverse variety of languages, frameworks, and other software.

Qualifications:

  • Know enough about a language to build a project using it.
    • JavaScript/Node.js
    • Python
    • Java
    • C
    • C++
    • C#
  • Self-starting creative problem-solver who finds multiple solutions to each problem, analyzes the pros and cons of each, and select the most appropriate solution for the problem at hand.
